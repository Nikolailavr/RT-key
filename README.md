# Ростелеком Ключ (RT-Key) — Custom Component for Home Assistant

[![HACS Validation](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/hacs/default)
[![Home Assistant](https://img.shields.io/badge/Home--Assistant-2023.8%2B-blue.svg)](https://www.home-assistant.io/)

Кастомная интеграция **Ростелеком Ключ** (`key.rt.ru`) для **Home Assistant**, распространяемая через **HACS**. 

Позволяет управлять умными домофонами, шлагбаумами, видеокамерами и генерировать гостевые PIN-коды прямо из Home Assistant, Telegram бота и панелей Lovelace.

---

## 🚀 Возможности

- **🔑 Умные Домофоны (`lock.py`)**: Открытие дверей подъезда и калиток из HA с автоматическим возвратом статуса «закрыто» через 5 секунд.
- **🚧 Шлагбаумы и Ворота (`lock.py`)**: Управление шлагбаумами двора и въездными группами.
- **📹 Видеонаблюдение (`camera.py`)**: RTSP/HLS видеопотоки и мгновенные JPEG-снапшоты с камер домофонов и двора.
- **🗝 Гостевые Коды (`sensor.py` / `services.yaml`)**: Создание одноразовых PIN-кодов для курьеров и гостей через сервис `rt_key.create_guest_code`.
- **🔘 Быстрые Кнопки (`button.py`)**: Элементы `button.open_door` и `button.open_barrier` для вызова в 1 клик.
- **🌐 Авторизация по SMS и Токену (`config_flow.py`)**: Интерактивная настройка с поддержкой отправки SMS или прямого ввода Bearer Token.

## 📥 Установка через HACS

1. Откройте **HACS** в Home Assistant.
2. Перейдите в раздел **Integrations** (Интеграции).
3. В правом верхнем углу нажмите **⋮** -> **Custom repositories** (Пользовательские репозитории).
4. Добавьте URL репозитория: `https://github.com/Nikolailavr/RT-key`
5. Выберите категорию: **Integration** (Интеграция) и нажмите **Add**.
6. Найдите **Ростелеком Ключ** в поиске и нажмите **Download** (Скачать).
7. Перезапустите Home Assistant.

---

## ⚙️ Настройка

1. Перейдите в **Настройки** -> **Устройства и службы** -> **Добавить интеграцию**.
2. Введите в поиске **Ростелеком Ключ**.
3. Выберите метод входа:
   - **SMS**: Введите номер телефона (`+79XXXXXXXXX`) и код из СМС.
   - **Token**: Введите скопированный Bearer Token.
